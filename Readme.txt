🍽️ Golden Restaurant Website

A modern, fully responsive restaurant website designed to showcase a restaurant’s brand, menu, and customer engagement features.
The project is live and deployed on Vercel, demonstrating a complete front-end web solution with clean UI and smooth responsiveness across devices.

✨ About the Project

The Golden Restaurant Website is a multi-page static web application built using core web technologies.
It provides an elegant and user-friendly interface for restaurant businesses to present their services, media content, and customer interaction forms.

The project focuses on responsive design, structured layout, and real-world deployment readiness.

🚀 Key Features

📱 Fully Responsive Design
Works seamlessly on desktop, tablet, and mobile devices

🗂️ Multi-Page Website Structure
Includes a main landing page and multiple inner pages

📝 Interactive Forms
Customer-facing forms for inquiries and interactions

🎥 Rich Media Support
Integrated assets including images and video content

🌍 Live Deployment
Hosted and deployed on the Vercel platform
